# AGR-001 – Architecture Governance Rules

Estado: APPROVED

1. Todo cambio estructural requiere ADR.
2. Ningún Engine modifica responsabilidades de otro.
3. Cambios de contratos actualizan el Contracts Catalog.
4. Cambios de modelos actualizan Canonical Models.
5. Cambios de Pipeline actualizan Blueprint, SPEC y Diagramas.
6. Ningún Engine nuevo sin Architecture Review.
7. Toda integración pasa por Integration Engine.
8. Business Brain decide.
9. La IA no gobierna el negocio.
10. Compatibilidad con CAB vigente.
