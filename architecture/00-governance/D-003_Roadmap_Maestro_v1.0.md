# 5. Reglas

1.  No se inicia una fase sin cerrar la anterior.
2.  Cada fase tendrá hasta cuatro entregables oficiales.
3.  No se implementa sin Specification aprobada.
4.  OpenCode implementa Specifications.
5.  CEO y CTO aprueban todos los entregables.
