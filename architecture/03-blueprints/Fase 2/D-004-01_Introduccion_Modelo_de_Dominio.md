# D-004-01 – Introducción al Modelo de Dominio

**Proyecto:** BotWA Starter  
**Documento:** Modelo de Dominio  
**Capítulo:** 01 – Introducción  
**Versión:** 1.0  
**Estado:** Aprobado

---

# Objetivo

Este documento introduce el Modelo de Dominio de BotWA Starter. Su propósito es definir el conocimiento del negocio que la plataforma deberá comprender para tomar decisiones correctamente.

No describe bases de datos, APIs ni tecnologías; describe el negocio.

---

# ¿Qué es el Dominio?

El dominio representa el conjunto de conceptos, reglas, relaciones y procesos que describen cómo funciona un negocio.

En BotWA Starter el dominio permite que la plataforma piense utilizando conceptos empresariales y no simplemente mensajes.

> Primero modelamos el negocio. Después modelamos el software.

---

# Propósito del Modelo de Dominio

1. Definir un lenguaje común.
2. Evitar ambigüedades.
3. Independizar el negocio de la tecnología.
4. Servir como base para Blueprints, Arquitectura Técnica y OpenCode.
5. Permitir la evolución del producto.

---

# Alcance

Este documento describe el dominio de BotWA Starter para cualquier MYPE. No modela industrias específicas.

---

# Principios del Dominio

- Dominio antes que tecnología.
- Lenguaje Ubicuo.
- Independencia del sector.
- Evolución controlada.
- El negocio es la fuente de verdad.

---

# Relación con la Arquitectura

La Fase 1 respondió **cómo está organizada BotWA**.

La Fase 2 responde **qué entiende BotWA sobre el negocio**.

---

# Decisión Arquitectónica

El Modelo de Dominio será independiente de tecnologías, proveedores, canales e implementaciones.

---

# CTO Review

El dominio es el activo intelectual más importante de BotWA Starter. Todas las fases posteriores deberán respetarlo.
