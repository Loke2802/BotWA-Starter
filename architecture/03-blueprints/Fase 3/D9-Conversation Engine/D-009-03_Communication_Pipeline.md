# D-009-03 – Communication Pipeline

Estado: Aprobado

## Objetivo
Definir el Pipeline de Comunicación del Conversation Engine.

Mensaje -> Message Receiver -> Conversation Context Builder -> Topic Detector -> Conversation State Manager -> Business Brain -> Response Composer -> Channel Adapter -> Respuesta

## Principios
- Comprensión antes que velocidad.
- Comunicación natural.
- Independencia del canal.
- Separación entre comunicación y decisiones.

## CTO Review
El Communication Pipeline es el flujo oficial de comunicación empresarial de BotWA.
