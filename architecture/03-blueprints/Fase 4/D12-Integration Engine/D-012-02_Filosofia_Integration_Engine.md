# D-012-02 – Filosofía del Integration Engine

**Estado:** Aprobado

## Filosofía
El Integration Engine representa la frontera tecnológica de BotWA.

## Principios
1. El Core nunca conoce la tecnología.
2. Toda integración pasa por adaptadores.
3. La tecnología es reemplazable.
4. Los contratos internos son estables.
5. La integración es resiliente.
6. Toda integración es observable.
7. La integración tiene límites claros.

## CTO Review
El Integration Engine permite evolucionar la tecnología sin afectar el Core.
