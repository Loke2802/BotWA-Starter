BotWA Starter

Política de privacidad

BotWA Starter procesa mensajes y datos técnicos necesarios para operar conversaciones de WhatsApp, administrar bots y gestionar atención humana. Los datos se usan únicamente para prestar y mejorar el servicio.

No vendemos datos personales. El acceso está limitado a usuarios autorizados y los datos sensibles se protegen mediante controles de acceso y cifrado.

Condiciones del servicio

BotWA Starter se ofrece actualmente como software en fase de prueba. El servicio puede cambiar, interrumpirse o limitarse durante la validación.

El usuario se compromete a utilizarlo de forma legal y conforme a las políticas de WhatsApp y Meta.

Eliminación de datos

Para solicitar la eliminación de datos relacionados con BotWA Starter, envía una solicitud al correo de contacto registrado en la aplicación de Meta. Incluye el número de teléfono asociado y una descripción de los datos que deseas eliminar.
